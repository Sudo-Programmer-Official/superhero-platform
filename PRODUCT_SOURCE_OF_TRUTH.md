# Product Source of Truth

## Mission
Build a premium, mobile-first platform for real-world practitioners to convert social attention into recurring in-person attendance.

## Primary MVP Goal
Deliver a working in-house MVP by June 10 to support filling the June 14 breathwork event.

## Primary Use Case
- Marla practitioner profile
- Transformational Breathwork Experience deal card
- Wallet pass flow
- Active payment flow
- Shareable experience

## Core User Flow
Practitioner:
Create Profile -> Create Deal -> Share Deal -> Customer Purchases -> Wallet Pass Generated -> Customer Redeems -> Attendance Tracked

Customer:
Instagram Story -> Open Deal -> Apple Pay -> Save Wallet Pass -> Attend Event -> Share With Friends

## Success Metrics
Primary KPI:
- weekly deal creation per practitioner

Secondary KPIs:
- redemption rate
- repeat attendance
- shares per deal
- repeat customers
