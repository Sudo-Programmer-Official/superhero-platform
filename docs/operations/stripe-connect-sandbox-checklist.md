# Stripe Connect Sandbox Checklist

## Setup
1. Enable Connect in Stripe test mode.
2. Configure Connect Express onboarding.
3. Create test platform account settings.
4. Verify webhook endpoint in staging API.

## Test Scenarios
- Practitioner onboarding link generation.
- Account status fetch and update.
- Checkout payment success/fail.
- Refund handling.
- Webhook signature verification.
