# Design System References

## Experience Targets
- Emotional and premium, not enterprise dashboard tone.
- Apple-native motion and spacing quality.
- High readability, calm contrast, and warm accent highlights.

## Tokens (Initial)
- Surface depth with layered panels
- Rounded corners for card stack language
- Typographic hierarchy optimized for mobile
- Motion: short ease-out transitions and staggered reveal

## Reuse Strategy
- Keep a shared `packages/ui` token and primitive layer.
- Build card/layout primitives once and reuse across onboarding, deals, wallet, and checkout.
- Keep native wrapper parity by avoiding desktop-only layout assumptions.
