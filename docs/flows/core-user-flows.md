# Core User Flows

Practitioner:
Create Profile -> Create Deal -> Share Deal -> Customer Purchases -> Wallet Pass Issued -> Redeem -> Attendance Tracked

Customer:
Story/Open Link -> Checkout -> Save Pass -> Attend -> Share

## Canonical MVP Loop
This is the small-business loop OpenMat should optimize for:

Create Deal -> Share Deal -> Claim Pass -> Redeem Pass -> Business Gets Customer -> Business Creates More Deals

## Haven Spa Example
Business owner:
1. Upload flyer image
2. Add title, offer, expiration, and eligible services
3. Publish deal
4. Share public link
5. Review claimed and redeemed counts

Customer:
1. Open shared link
2. View deal
3. Enter name, email, and phone
4. Save pass
5. Show QR at redemption

Operator:
1. Open scanner
2. Scan pass QR
3. Confirm valid redemption
4. See deal name and recent activity
